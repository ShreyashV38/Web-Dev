# Classical Dinosaur Game

## Description
This is a classical, endless running dinosaur game created using HTML, CSS, and Vanilla JavaScript. It fulfills the assignment constraints of using basic web technologies to build a game where a character avoids obstacles.

## Features
- Arrow keys movement (Up, Down, Left, Right).
- Randomly generated obstacles that move across the screen.
- Collision detection using bounding boxes.
- Web Audio API used for sound generation upon collision (`bloop´ sound effect).
- Time-based progression: the game speed subtly increases the longer you survive.
- Clean and minimal UI.

## How to Play
1. Open `code/index.html` in your web browser.
2. Click the **Start Game** button.
3. Use the **Up** arrow to jump over obstacles.
4. Use the **Down** arrow to duck under high obstacles (though in this classic mode, most are low!).
5. Use **Left** and **Right** arrows to adjust your horizontal position on the screen to avoid tricky patterns.
6. Survive as long as possible to achieve a high score!
